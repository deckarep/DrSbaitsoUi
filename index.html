  1. Unzip it (Safari does this for you), then drag Dr. Sbaitso Reborn into your Applications folder.
  2. The app isn't notarized by Apple, so macOS quarantines it and refuses to open it. To clear the quarantine flag, open Terminal and run:

Windows · x64
DrSbaitsoReborn-__APP_VERSION__-Windows-x64.zip · 64-bit Windows 10 or 11
Download
  1. Before unzipping, right-click the zip, choose Properties, tick Unblock at the bottom, and click OK. This clears the “downloaded from the internet” mark, so Windows won't block the app.
  2. Right-click the zip and choose Extract All…. Don't run it from inside the zip, because the app needs the resources folder that sits next to it.
  3. Open the extracted folder and double-click DrSbaitsoUI.exe.

If you see “Windows protected your PC” anyway, click More info, then Run anyway. Windows shows this because the app isn't code-signed.
